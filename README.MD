   ```bash
   git clone https://github.com/usuario/nombre-del-repositorio.git
   ```

2. **Abrir el proyecto en Visual Studio Code**
   ```bash
   cd nombre-del-repositorio
   code .
   ```

3. **Explorar la estructura del proyecto**
   ```
   📁 proyecto/
   ├── index.html
   ├── styles.css
   └── README.md
   ```

4. **Ejecutar la aplicación**
   - Abre el archivo `index.html` directamente en tu navegador, o
   - Usa la extensión **Live Server** de Visual Studio Code para verlo en tiempo real.

5. **Realizar cambios o mejoras**
   - Crea una nueva rama antes de modificar el código:
     ```bash
     git checkout -b nombre-de-tu-rama
     ```

6. **Subir tus cambios**
   ```bash
   git add .
   git commit -m "Descripción breve del cambio"
   git push origin nombre-de-tu-rama
   ```

7. **Crear un Pull Request**
   - Ve al repositorio en GitHub y abre un Pull Request describiendo los cambios realizados para que sean revisados.
